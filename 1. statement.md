Problem Statement & Project Scope
1. Problem Statement
Traditional manual attendance recording in educational institutions is time-consuming, prone to human error, and susceptible to proxy attendance. Additionally, attendance records are rarely correlated in real-time with academic performance indicators, preventing timely interventions for low-performing or frequently absent students[cite: 1].

2. Project Scope
The Smart Attendance Management and Student Performance Tracking System addresses these challenges by automating attendance logging using computer vision and facial recognition. The system automatically updates student records, analyzes attendance trends alongside academic metrics, and employs machine learning to flag at-risk students for proactive academic counseling.

3. Target Users
Faculty / Instructors: To capture automated classroom attendance and review real-time performance analytics.
Academic Counselors / HODs: To view early warnings for at-risk students based on combined attendance and test score metrics.
Students: To track personal attendance trends, academic progress, and risk flags via a web dashboard.
System Administrators: To manage user accounts, update face datasets, and configure system thresholds.
4. High-Level Features
Automated Face Recognition Attendance: Rapid, contact-free facial verification.
Student Performance Analytics: Integrated dashboard displaying marks, attendance rates, and risk status.
Predictive At-Risk Student Identification: Machine Learning classification identifying students needing early intervention.
Role-Based Web Portal: Secure access customized for Admins, Faculty, and Students.
Automated Notifications & Reports: Exportable PDF/Excel attendance summaries and risk alerts.
